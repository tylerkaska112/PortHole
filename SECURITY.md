# Security

If you find a security problem in Porthole, please report it **privately** and not as a public issue:

- Use **Report a vulnerability** under this repository's **Security** tab. Only the maintainer sees it.

Please include what you found, how to reproduce it, and which version you tested. This is a hobby project run by one person, so there is
no bounty and no fixed response time, but reports are read and taken seriously.

Things worth reporting: anything that could expose a store sign-in (Steam, Epic Games, GOG or an itch.io API key), a signing certificate or
pairing file, lets an update install without the maintainer's signature, lets another app or web page drive Porthole through its links, or
sends data the privacy page does not describe.
