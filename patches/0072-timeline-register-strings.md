# 0072 timeline: the text the registers point at (diagnostic, Black Ops 3 only)

`server_ios.c`. Offline analysis showed the endless loop is inside the game's own copy of a GetProcAddress-like export walker (name compared as text, case-insensitively; no hashing: the 64-bit constants in the code are compare targets, `movabs r,K; add r,rdx; je`, and no plain FNV variant reproduces them). Which name it is asked for is the open question. The timeline now samples every 20 ms and, whenever the set of registers that point at printable text (5+ characters) changes, writes `Documents/bo3-timeline/strings.txt`: `ms rip rsp reg="text" ...` (6000 lines at most). During the 12 s before the loop the walker compares the wanted name with the names of the export table, so the wanted name and the last name it was looking for should be in there.
