# 0145 FEX: L1 miss census (log only)

`FEXCore/Source/Interface/Core/LookupCache.h` (submodule FEX). With every `[l1-miss]` line (each 2^20 misses, process-wide) a second line says how many misses found the slot empty and how many found another block in it (a conflict of the direct-mapped L1, indexed by the low 17 bits of the guest address), and the eight heaviest missing guest addresses (sampled every 16th miss, Misra-Gries in 4096 hashed slots, count x16).
Reason: the profile of The Forest 2026-10-14 23:28 put 7 % + 3.4 % of the main thread in `LookupCache::CacheBlockMapping` / `UpdateDynamicL1Stats` / the ankerl hash maps and `BeginSimulation`, with 75-95K L1 misses a second (`[l1-miss]` lines) and `CB_SUMMARY` hit rate 98 % (the C++ lookup finds the block in the shared map; only the inline L1 probe misses). Each miss takes the shared read lock and a hash lookup (~1.5-2 us).

The array is reserved at the larger size for every thread (VA only).
